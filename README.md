# Spascle
Spascle (Scientific Programming and Computational Science Learning Environment) is an AI-powered, self paced, online learning platform that helps beginners from materials science, chemistry and other science disciplines learn scientific programming through relatable explanations and exercises to gain directly applicable skills for their field. This Project was initially called Prosca before I changed the name to Spascle. As you go through the codebase you may still find the name Prosca mentioned. It's the same thing.
