SPASCLE FRONTEND - EXTERNAL TOOLS AND SERVICES
==============================================
Last updated: 3 November 2026

Everything the frontend depends on that was not written for this project.
Update this file whenever a package, CDN or external service is added or removed.


1. SERVICES LOADED FROM THE INTERNET AT RUNTIME
-----------------------------------------------
These are fetched by the learner's browser, not bundled with the app.
If a CDN is unreachable, the related feature degrades (see "If unavailable").

Pyodide (Python runtime compiled to WebAssembly)
  Version:        314.0.7  (set in lib/python-runner.ts -> PYODIDE_VERSION)
  Loaded from:    https://cdn.jsdelivr.net/pyodide/v314.0.7/full/
  Used for:       Running learners' Python code in the browser ("Try it hands-on").
                  Runs inside a module Web Worker: public/workers/python-worker.js
  Download size:  About 10 MB on the first run, then cached by the browser.
  License:        MPL-2.0
  Website:        https://pyodide.org
  If unavailable: The editor shows "Python is unavailable" with a Try again button.
                  Lessons stay readable.
  Note:           Pyodide 314+ only works in module workers
                  (new Worker(url, { type: "module" })).

Monaco Editor (the code editor used in VS Code)
  Version:        0.55.1  (default of @monaco-editor/loader 1.7.0)
  Loaded from:    https://cdn.jsdelivr.net/npm/monaco-editor@0.55.1/min/vs
  Used for:       The editable code area in "Try it hands-on".
  License:        MIT
  Website:        https://microsoft.github.io/monaco-editor/
  If unavailable: The editor area stays on "Loading editor...".

jsDelivr (CDN hosting Pyodide and Monaco)
  Website:        https://www.jsdelivr.com
  Note:           Both runtime downloads above come from this CDN. To remove the
                  dependency later, self-host the files and change the URLs.

Google Fonts via next/font (Inter, JetBrains Mono)
  Used for:       Interface font (Inter) and code font (JetBrains Mono).
  Configured in:  app/layout.tsx
  License:        SIL Open Font License 1.1 (both fonts)
  Note:           next/font downloads the fonts at BUILD time and serves them
                  from the app, so browsers do not contact Google at runtime.
